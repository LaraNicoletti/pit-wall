## 💻 Sobre o Projeto

### 📖 Descrição

O Pitwall é um projeto de desenvolvimento web que consiste na criação de uma página inspirada no universo da Fórmula 1. O site foi desenvolvido com base em uma imagem de referência, buscando reproduzir sua identidade visual, organização dos elementos e características estéticas.

A página apresenta elementos relacionados ao automobilismo e à Fórmula 1, utilizando recursos visuais para proporcionar uma experiência agradável e uma navegação intuitiva ao usuário.

### 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma página web utilizando HTML e CSS, aplicando conceitos de estruturação, estilização e organização de elementos visuais. Além disso, busca-se reproduzir uma referência visual por meio de código, desenvolvendo habilidades de interpretação de layouts e construção de interfaces.

### 💡 Finalidade

O projeto foi desenvolvido com a finalidade de aplicar, na prática, os conhecimentos adquiridos durante o curso, proporcionando experiência no desenvolvimento de soluções tecnológicas e na utilização das ferramentas e linguagens estudadas.

### 🛠️ Ferramentas e Tecnologias Utilizadas

As seguintes ferramentas e tecnologias foram utilizadas durante o desenvolvimento:

- HTML: Utilizado para estruturar o conteúdo da página, organizando textos, imagens, links e demais elementos.

- CSS: Responsável pela estilização da página, incluindo cores, fontes, espaçamentos, posicionamento e organização dos elementos visuais.

- Visual Studio Code: Editor de código utilizado para escrever, organizar e editar os arquivos do projeto.
